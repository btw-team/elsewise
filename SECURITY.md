# Security Policy

## Supported versions

Elsewise is currently in early development. Security fixes are provided for the latest published release only.

| Version        | Supported |
| -------------- | --------- |
| Latest release | Yes       |
| Older releases | No        |

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Use [GitHub's private vulnerability reporting](https://github.com/btw-team/elsewise/security/advisories/new) instead. Include the affected version, operating system, reproduction steps, impact, and any suggested mitigation when available.

Before submitting logs, screenshots, databases, or configuration files, remove meeting content, pairing tokens, API credentials, local paths, and other personal or confidential information.

Reports will be reviewed privately. We will coordinate disclosure and publication of a fix with the reporter when appropriate.
