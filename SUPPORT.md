# Support

Elsewise is an open-source project maintained by the community. Before asking for help, check the [documentation](https://github.com/btw-team/elsewise/tree/main/docs) and the [existing issues](https://github.com/btw-team/elsewise/issues).

## Ask for help or report a problem

Use the [GitHub issue forms](https://github.com/btw-team/elsewise/issues/new/choose) for reproducible bugs and focused feature requests. Include the Elsewise version, operating system, browser, meeting provider, and enough redacted detail to reproduce the problem.

Do not post meeting transcripts, participant information, pairing tokens, credentials, unsanitized DOM captures, or other sensitive data.

## Security vulnerabilities

Do not report suspected vulnerabilities in a public issue. Follow the [security policy](https://github.com/btw-team/elsewise/security/policy) and submit a [private security advisory](https://github.com/btw-team/elsewise/security/advisories/new).

## Commercial support

This repository does not currently provide a commercial support channel or response-time guarantee.
