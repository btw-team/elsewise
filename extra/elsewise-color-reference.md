# Elsewise color reference

Quick reference for the primary interface colors. The authoritative source for
all semantic tokens is
[`shared/theme-tokens.json`](../shared/theme-tokens.json).

| Purpose        | Dark theme | Light theme | Primary use                                  |
| -------------- | ---------- | ----------- | -------------------------------------------- |
| Canvas         | `#1b2229`  | `#f7fafb`   | Application background                       |
| Panels         | `#202a33`  | `#ffffff`   | Columns, modal dialogs, and major regions     |
| Surfaces       | `#26313b`  | `#ffffff`   | Cards and controls                           |
| Active surface | `#354550`  | `#e4eef1`   | Selected elements and states                 |
| Borders        | `#3b4b57`  | `#d4e0e4`   | Cards, fields, and dividers                  |
| Primary text   | `#edf5f7`  | `#11191e`   | Headings and body text                       |
| Muted text     | `#9babb3`  | `#586c75`   | Labels and secondary information             |
| Cyan accent    | `#03b8e9`  | `#038ab3`   | Primary actions, links, and brand details    |
| Teal accent    | `#17d3cf`  | `#09bfbd`   | Gradients and selected states                |
| Success        | `#70d89d`  | `#176b40`   | Successful and connected states              |
| Warning        | `#f2bd63`  | `#825300`   | Warnings and intermediate states             |
| Danger         | `#ff858d`  | `#a92030`   | Errors and destructive actions               |
| Focus ring     | `#36d1ef`  | `#038ab3`   | Visible focus during keyboard navigation     |
